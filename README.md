# Выпускная квалификационная работа

## по теме: "Неструктурированные сетки в задачах моделирования динамических систем с неопределенностями в параметрах"

Выполнила Ирина Сектименко, студент группы М8О-410Б-22.
Научный руководитель - Александр Юрьевич Морозов, доктор физико-математических наук, доцент.

Программа состоит из файлов:
- build_grid_circle.py - аппроксимация области начальных условий и построение начальной сетки методом продвигаемого фронта.
- num_method.py - численный метод Рунге-Кутты 4-ого порядка с адаптивной интерполяцией.
- interpolation.py - интерполяция на начальном временном слое.
- interpolation_on_adaptive_grid.py - вычисление значений на следующих временных слоях.
- calculation.py - вычисление погрешности решения.
